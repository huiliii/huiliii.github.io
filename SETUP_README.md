# Huili Sun — Academic Pages site

This is your new website, migrated to the Academic Pages template.

## Before it goes live, add two files:
1. Copy your photo to:  images/profile.png   (your old me.png)
2. Copy your CV to:     files/cv.pdf          (your old cv.pdf)

## To publish:
1. On GitHub, rename your repo to `huiliii.github.io` (Settings > Repository name).
2. Replace the repo contents with these files (or push this folder to a fresh commit).
3. In repo Settings > Pages, confirm the source is the `main` branch.
4. Site goes live at https://huiliii.github.io

## To edit later:
- Bio / research text:  _pages/about.md
- Publications:         one .md file each in _publications/
- CV page:              _pages/cv.md
- Name, links, email:   _config.yml (author section)
